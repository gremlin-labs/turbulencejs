Turbulence

A Delightfully Retro Animation Library

Buttons Dialogs Toasts Transitions Docs

Add delightful, cartoonish motion to your UI

Turbulence brings that classic 1930s animation feel to modern web apps. Like a dancing cartoon character, your elements will bounce, squash, stretch and pop with personality!

Cartoonish Button Effects

Boing!
Exaggerated squash and stretch.
Jelly
Wobbly, gelatinous effect.
Explode
Burst effect with particles.
Spring Crazy
Wild bouncing spring effect.
Poof!
Disappear in a puff of smoke.
Rubber Band
Stretches and snaps back (Hover).

Dramatic Dialog Effects

Click buttons to open a modal with different animations.

Quick Start

Add Turbulence to your project:

npm install turbulencejs

Basic usage:

import turbulencejs from 'turbulencejs';
const button = document.querySelector('.my-button');
button.addEventListener('click', () => turbulencejs.buttons.boing(button));
