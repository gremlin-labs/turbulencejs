# TurbulenceJS agent skills

The [`turbulencejs-integration`](turbulencejs-integration/SKILL.md) skill helps an agent choose and integrate the appropriate TurbulenceJS entrypoints, motion style, and intensity for a web or Electron project.

The skill is portable: copy its complete folder into an agent's skill directory. It includes its own work-artifact contract, catalog, templates, and read-only project inspector; it does not require gremlin-skills or another skill package.

See [the installation and implementation guide](../docs/agent-skill.md).
